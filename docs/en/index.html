Multiplayer CFR Poker AI Engine

A C++ research engine connecting multiplayer game state, information sets, regret updates, average strategy, and action inference.

GitHub repository

Engine capabilities

Multiplayer state

Seats, stacks, boards, betting rounds, legal actions, and terminal utility.

CFR self-play

Information-set regret, average policy, MCCFR sampling, and iterative training.

Action inference

Loads a strategy for the current state and selects fold, call, or raise for evaluation.

From poker rules to AI policy

The engine follows a hand from private cards and blinds through preflop, flop, turn, and river. At each decision it constructs an information set, enumerates legal actions, and samples a policy. Terminal payoff then feeds regret and average-strategy updates. Multiple opponents add positional, effective-stack, and action-order complexity.

state → information set / abstraction → legal actions → policy → utility → regret update
